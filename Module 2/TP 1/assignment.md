# Practical Assignment No. 1 – Design Your Own Application

## Objective
During Module 2, you will develop your own application using AI as a development assistant. In this first submission, you will not write any code. Your goal is to correctly design the project so that an agent can understand it and begin building it in the upcoming classes.

## Instructions
Choose an application idea (it can be your own idea or inspired by an everyday problem) and complete the following sections.

### 1. Define the Problem
Briefly answer:
* What problem does the application solve?
* Who would use it?
* Why would it be useful?

### 2. Main Features
Define at least 5 features.
*Example:*
* Create an item.
* Edit it.
* Delete it.
* Search.
* Filter.

### 3. Main Data
Indicate what information each record will contain.
*Example:*
* Title
* Description
* Category
* Status
* Creation Date
* Favorite

### 4. Write a Short SPEC
No more than one page. It must include:
* Objective.
* User.
* Features.
* Constraints.
* Chosen technology (if you already know it).

### 5. Write a Professional Prompt
Imagine you are handing it to Cursor or Claude Code. The prompt must clearly explain:
* What you want to build.
* What technology to use.
* What features it must have.
* How you expect the code to look.
* What important constraints it must respect.

### 6. Define your Validation Challenge
Before accepting the code generated by the AI, answer: What would you validate?
*For example:*
* Does it work correctly?
* Is it easy to understand?
* Does it respect the expected structure?
* Are the data saved correctly?
* Is the interface clear?
* Is there error handling?

---

## Deliverable
A single Markdown file with the following structure:
# Project Name
## Problem
## Features
## Data
## SPEC
## Professional Prompt
## Validation Challenge

**Important:** We do NOT want code yet. In the next class, we will use this document to start building the application together with an AI agent. The better the project is defined, the better the results you will obtain during development.
