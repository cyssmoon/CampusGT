# Mini Activity – Refactoring + Unit Testing

## Assignment Objective
Select a functioning feature or component from your project and perform a refactoring process followed by comprehensive unit testing.

## Requirements
1. **AI Analysis:** Ask the AI to detect:
   * Code duplication.
   * Overly long functions or components.
   * Unclear naming conventions.
   * Mixed responsibilities.
   * Opportunities for simplification.
2. **Refactoring:** Select a single improvement and refactor the code without altering the feature's behavior.
3. **Unit Testing:** Generate necessary unit tests, including:
   * A correct case.
   * An invalid data case.
   * An edge case.
4. **Verification:** Execute the tests and ensure they pass after refactoring.

## Suggested Prompt
*   "Read the project's SPEC and AGENTS.md."
*   "Analyze only this specific functionality."
*   "Do not write code yet. Detect refactoring opportunities and propose a concrete improvement."
*   "After my approval: implement the improvement, maintain behavior, generate unit tests (correct, invalid, edge cases), and explain what each test validates."
*   "Do not proceed with other functionalities."

## Deliverables
*   Code before and after refactoring.
*   Brief explanation of the improvement made.
*   Generated unit tests.
*   Results of the test execution.
